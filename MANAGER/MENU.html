＋ 서브 메뉴 추가

메뉴는 메인 메뉴(EGMM · HMART …) → 서브 메뉴 구조로 관리되며, 이름이 아닌 코드로 관리됩니다 (예: MENU-PLU-LIST). 코드는 직급·부서·메뉴·마트 전체에서 중복될 수 없습니다. 각 서브 메뉴의 [권한] 버튼에서 아이디별 · 직급별 허용을 설정하고, 레벨(LV)을 지정하면 그 레벨 이하(숫자가 작거나 같은) 계정에게 표시됩니다. LV-0 계정은 항상 모든 메뉴를 봅니다. SYSTEM 카테고리(ACCESS·STORE·DEPARTMENT·MENU·FUNCTION CODE)는 관리자 모드 — LV-0 전용입니다.
EGMM 포털에 이미 만들어진 메뉴(파일) 전체를 한 번에 등록합니다 — 이미 있는 코드는 건너뜁니다.

🌐 메인 메뉴 관리

메인 메뉴는 EGMM · HMART 처럼 서브 메뉴를 묶는 상위 분류입니다. 전체는 기본 포함 — 메인 메뉴를 '전체'로 지정한 서브 메뉴는 모든 메인 메뉴에서 표시됩니다. 이름은 중복될 수 없으며(중복 시 경고), 서브 메뉴가 사용 중인 메인 메뉴는 삭제할 수 없습니다.
