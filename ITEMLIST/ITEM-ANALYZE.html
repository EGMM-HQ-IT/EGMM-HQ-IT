📖 규칙 가이드

  1. 업로드 파일POS 리포트 상품별 일단위 판매현황(prsalesitemperdate.xls) 원본 그대로. 시트가 여러 개면 모두 이어서 읽음. 매장 카드에 파일을 끌어다 놓거나 선택 — 날짜 선택 없음.
  2. 열 규칙A열 = UPC (맨 앞 0 무시, 7자리 이상 숫자만 인정) · C열 = 날짜 · D열 = 그날 판매 금액. A열이 비어 있는 행은 바로 위 UPC 의 다른 날짜 판매로 읽음. 소계·계·총계·Page 줄, 0/마이너스 금액은 건너뜀.
  3. 판매가 · 수량한 UPC 의 날짜별 금액 중 가장 낮은 금액 = 판매가(단가). 날짜별 수량 = 그날 금액 ÷ 단가 (4.99 → 1개, 9.98 → 2개, 14.97 → 3개, 나누어떨어지지 않으면 반올림).
  4. 저장 (쌓기)매장별로 Firebase 에 압축 저장. 같은 UPC·날짜는 새 값으로 덮고 나머지 날짜는 유지 — 월마다 올리면 계속 쌓임. 업로드 전 확인 팝업에서 기간·상품수·판매수를 확인.
  5. 매장별 판매 차트날짜별 업체 누적 막대 (STI-WA 녹색 · JFC 노란색 · WIC 오렌지색). 5일씩 표시, ◀ 이전 / 다음 ▶ 로 이동. UPC MANAGER 미등록 UPC 는 차트에서 제외.
  6. 상품 검색UPC 또는 상품명. UPC 는 앞 0 무시, 상품명은 빈칸 무시. 결과는 판매가와 날짜 × 매장 수량표, 5개까지 표시 후 스크롤.
  7. 업체별 판매 비율날짜와 상관없이 전체 데이터. 판매된 UPC 개수 기준 (한 UPC 가 30일 팔려도 1개). 판매된 아이템 기준 = 업체별 점유율 도넛 · 등록된 아이템 기준 = 업체별 등록 대비 판매된 UPC 비율. 전체 / 매장별 / 선택 매장 보기.
  8. 상품 · 업체 기준상품과 업체(VENDER) 는 UPC MANAGER 등록 데이터 기준. 상품 목록은 변경 시 자동 갱신, ↻ 새로고침으로 즉시 다시 불러옴.
